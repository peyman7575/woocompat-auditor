# WooCompat Auditor 0.2.0

WooCompat Auditor 0.2.0 turns the initial read-only diagnostic plugin into a more reproducible open-source project with tested compatibility auditing and a maintainable release pipeline.

## Highlights

- Adds active WooCommerce extension compatibility declaration auditing for:
  - High-Performance Order Storage (HPOS)
  - Cart and Checkout Blocks
- Distinguishes explicit incompatibility from a missing compatibility declaration.
- Keeps missing declarations informational rather than treating them as known failures.
- Exposes only plugin basenames and versions in compatibility context.
- Adds PHPUnit coverage for report behavior and compatibility classification.
- Adds CI syntax validation across PHP 7.4 through PHP 8.4.
- Runs PHPUnit on PHP 7.4, 8.1, and 8.4.
- Enforces WordPress Coding Standards, Composer metadata validation, and synchronized version metadata.
- Builds a reproducible, installable single-root plugin ZIP.
- Adds PR-driven release automation with a full quality gate before publication.

## Safety and privacy

The auditor remains read-only. It does not change WooCommerce settings, send telemetry, or intentionally export credentials, authentication material, customer/order data, or absolute filesystem paths.

## Upgrade notes

No database migration is required from 0.1.0. Replace the previous plugin files with the 0.2.0 package and run the audit again.
